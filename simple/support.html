Support

Election Time · Punjab Assembly

Write to [SUPPORT EMAIL]. If it is about a particular election, include the game code — it is on the lobby screen and in the Continue card on the opening screen.

I lost my profile

Your profile lives in the browser you played in. Clearing site data, or opening the game in a different browser or in private mode, means a new profile. There is no password to recover it with, because there is no account — this is the trade for not asking you for an email address.

I cannot rejoin my game

An election in progress is offered back on the opening screen as Continue Election. If it is not there, the game may have finished or been ended by the host. You can also rejoin by entering the game code through Play / Join Election.

Nobody else can join my game

Share the five-letter game code. Up to four people can play, and the election starts when the host begins it. A fifth person is turned away.

The game will not load

Refresh once and wait a moment. If the page loads but the game does not start, the host's content network occasionally answers a rapid burst of requests with a challenge page; waiting a minute and retrying clears it.

Deleting your profile

Open My Profile and choose Delete my profile. It removes your name, your face and your record from the server, and clears everything this browser kept. It cannot be undone.

Elections you played stay as they are, because other people played them too. If you would rather we did it for you, write to [SUPPORT EMAIL].

Privacy requests

To ask what the game holds about you, to correct it, or to have it removed, write to [SUPPORT EMAIL]. Everything the game holds is also visible to you on the My Profile screen.

See also the privacy page.

Reporting a player or a name

If another player has used an abusive or impersonating party name, or behaved in a way that spoiled an election, write to [SUPPORT EMAIL] with the game code and what you saw.
